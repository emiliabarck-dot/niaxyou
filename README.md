# Nia x You Next.js Website

## Run locally

```bash
cd niaxyou-nextjs
rm -rf node_modules package-lock.json .next
npm install
npm run dev
```

Open http://localhost:3000

## Updates in this version

- Plain and Floral cover selections now keep the same orientation when switching buttons.
- Design selection now only shows Plain and Floral.
- Dragging up tilts the cover upward.
- Stronger top lighting helps show floral detail.
